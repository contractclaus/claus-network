# Claus review boundary

Exact agent-side source supplied for independent review. These files run in the separate Claus agent deployment; the network package does not import or execute them. The deployment verifies these source hashes against the agent release. Configuration and secrets are not included.

`network-review.ts` persists the original validated input and generated request before dispatch, and sends the saved request once. Existing requests are not regenerated by later format changes. `network-review-schema.ts` validates the evidence and creates the lossless shared-input view. `network-signal-review.ts` validates the bounded signal consumer.
