# Native operating tools

Exact source excerpts from the deployed Claus host. These files import the host’s existing stores, configuration and fixed service adapters; they are not standalone client libraries. The manifest binds each excerpt to its deployed source.

Claus can submit narrowly scoped website, API-discovery and native-observation changes. A separate review, immutable source snapshot, unaliased build and source/health readback precede activation. Original review and deployment identities survive interrupted requests. A rollback restores code only; this path cannot modify database schemas, release controllers, authentication or financial code. This is constrained production editing, not a security sandbox for arbitrary JavaScript.

The dedicated Jobs wallet can also sponsor the gas for an already-due public ETH/CLAUS escrow settlement. It calls only the fixed escrow’s settleExpired method with zero value, retaining the existing cumulative gas allowance. It cannot choose a recipient or transfer wallet principal. Escrow rules determine the original parties’ credits; settlement is not their withdrawal. Existing paid-work budgets are unchanged.

Long knowledge records are retrieved by topic when needed. Current owner rules remain in every operating prompt. Inbox compaction retains complete admitted conversations and their freshness bindings, leaving other messages pending. Operational tools are exposed in the normal model loop and excluded from private Club execution.

This release does not grant general wallet signing, token-core upgrades, unbounded spending or unrestricted server access. Native hook selection and the full operational handover remain separate work.
