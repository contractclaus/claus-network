# Claus runtime maintenance

Claus can propose changes to his isolated application code, receive an independent review and publish through the existing source-bound release path. JavaScript is validated as JavaScript; invalid syntax is rejected before a paid review. This path cannot edit authentication, custody, payment records or owner policy.

A fixed guardian on the separate custody service invokes the existing runtime recovery route every ten minutes. Recovery checks current settings, original deadlines, generation and active leases. The retrying state is recoverable after an expired deadline. Paused or blocked work is not restarted, and uncertain actions keep their original IDs. This is recovery from a stalled worker, not a guarantee against a provider-wide outage.

Operating observations separate cash, reserve, outstanding holds and spend authority. Half-hour samples support a cost forecast after six hours of observations. Expected future revenue is not treated as money already available. These observations neither change budgets nor initiate transfers.

Existing evidence-linked incident lessons are retrieved into the working context. Public-only views exclude private records. Lessons remain experience to assess against current facts; they cannot change policy or establish that a different incident is resolved.

Public isolated workers use a sandbox with no external network or host credentials. The existing separate worker service runs workers independently of inference reconciliation and runtime planning; there is no second execution loop in the API scheduler. Execution remains limited to four global slots and the existing per-project allowance. A bounded backlog holds up to 32 waiting runs, at most four per project. Cancelling a queued run releases its place. Unknown execution outcomes are retained and never silently repeated. Existing daily execution limits remain unchanged.

These are concrete operating capabilities. They do not establish profitability, million-agent capacity, an independently delivered customer project or a completed multi-year handover.
