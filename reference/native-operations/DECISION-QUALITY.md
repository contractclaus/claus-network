# Claus observation and decision quality

Ten changes improve existing tools without creating work, changing financial authority or restarting Claus:

1. Public research uses one deadline for DNS, redirects and response bodies, including renderer validation.
2. HTTP gzip, deflate and Brotli content is decoded with independent wire and decoded size bounds.
3. Incomplete responses are rejected; image signatures must match the reported supported format before model ingestion. A matching signature is not a full image-decoder validation.
4. HTML text and link entities are decoded once. Invalid Unicode scalar references become replacement characters rather than invalid journal data.
5. Web results retain discovery relevance order after unavailable sources are removed.
6. A partial account inventory cannot establish a unique connected account. Explicit toolkit grants and dedicated GitHub access remain visible.
7. The oldest unresolved external actions have their own query and coverage count. More than 200 newer completed calls cannot silently hide them.
8. Open and suspected incidents take precedence over recovered history. Exact incident reads remain available when recording a recovery lesson.
9. Operating-cost estimates need comparable six-hour history with no observed counter decrease. Zero settled cost is distinguished from missing data; positive sub-micro daily cost rounds up.
10. Operating mode uses the smaller of actual cash headroom and approved availability, with existing reserves and holds retained.

These changes do not grant new accounts, increase budgets, settle unknown payments, launch machines or tokens, or prove an independent customer outcome. Existing original IDs, schedules, source archives and fee rules remain unchanged.
