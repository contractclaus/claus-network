# Fixed operational and surface publisher

This directory is a reference source subset, not a standalone service distribution. Operational publishing is described in [PUBLISHER-BOUNDARY.md](PUBLISHER-BOUNDARY.md); the Network surface route and original-attempt journal are described in [SURFACE-PUBLISHER-BOUNDARY.md](SURFACE-PUBLISHER-BOUNDARY.md). The Native runtime role and separate configuration custodian are described in [NATIVE-DATABASE-BOUNDARY.md](NATIVE-DATABASE-BOUNDARY.md). The manifests identify the deployed source. Native and API editing scopes remain limited; general host/database isolation is incomplete.

The independent payer now binds review requests and complete verdicts; see [review evidence](REVIEW-EVIDENCE-BOUNDARY.md). Native-written review copies cannot grant publishing authority.

[Publication authority](PUBLICATION-CONTROL-BOUNDARY.md) describes fixed activation, immutable source and protected runner pins.

[Publication recovery](PUBLICATION-RECOVERY.md) documents original-receipt recovery and current production checks.

[Owner missions and action evidence](WORK-EVIDENCE-BOUNDARY.md) describes fixed owner admission and immutable settled action receipts.

[Fixed social sender](SOCIAL-BOUNDARY.md) describes separated X credentials and original publication receipts.

[Recovery and operating capacity](RELIABLE-RECOVERY.md) describes original receipt reconciliation, bounded buyback recovery and separate resource accounting.

[Network session recovery](NETWORK-SESSION-RECOVERY.md) describes targeted session renewal without replaying actions.

[Search credential boundary](SEARCH-BOUNDARY.md) describes fixed provider search with independent request accounting.
