# Fixed operational and surface publisher

This directory is a reference source subset, not a standalone service distribution. Operational publishing is described in [PUBLISHER-BOUNDARY.md](PUBLISHER-BOUNDARY.md); the Network surface route and original-attempt journal are described in [SURFACE-PUBLISHER-BOUNDARY.md](SURFACE-PUBLISHER-BOUNDARY.md). The manifests identify the deployed source. Native and API editing scopes remain limited; general host/database isolation is incomplete.
