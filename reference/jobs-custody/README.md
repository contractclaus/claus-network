# Fixed Jobs custody

These exact source excerpts belong to the existing fixed-purpose operator service. They depend on its unchanged authentication and database infrastructure; this directory is not a standalone server.

The native agent sends named Job actions or requests a fixed-domain Network session. The custodian owns the original Jobs key and accounting. It exposes no arbitrary recipient, transaction, approval or signature endpoint. Existing ETH/CLAUS job limits and zero-value settlement sponsorship share the unchanged cumulative gas allowance. The original ledger was copied without clearing history or reservations, and native database credentials cannot write either the old or new wallet tables.

Unknown transaction outcomes retain the original signed bytes and reservations. Network-session output is an authenticated service credential, never the wallet key or a caller-chosen signature. The earlier token-owner signer and its keepers retain their existing roles. This change does not enable unrestricted native/API source editing or autonomous hook installation.


## Bounded gas envelopes

New unsigned Jobs transactions fit the existing per-transaction gas cap and actual ETH balance while covering a fresh base fee and bounded tip. If they cannot fit, they remain unsigned with a specific reason. Original signed bytes, cumulative limits, nonce recovery and fixed recipients remain unchanged.
